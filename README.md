# Shopify Sales & Customer Analytics

## Project Overview
This project analyses Shopify sales transaction data to understand sales performance, product contribution, geographic distribution, payment gateway usage, and customer purchasing behaviour.

An AI-assisted dashboard was created using Julius AI to transform transaction data into visual insights for business decision-making.

## Business Objectives
- Evaluate total recorded sales and order performance.
- Identify the best-performing product categories.
- Compare sales across billing states and cities.
- Understand the distribution of payment gateway usage.
- Analyse customer purchase frequency during the observed period.
- Recommend actions based on the findings.

## Tools & Technologies
- **Julius AI:** AI-assisted data analysis and dashboard creation
- **Microsoft Excel:** Dataset preparation and inspection
- **GitHub:** Project documentation and portfolio hosting
- **Power BI:** Planned extension for interactive reporting and DAX analysis

## Dataset Overview
- **Reporting period:** March 18–24, 2025
- **Geographic scope:** United States billing locations
- **Currency:** USD
- **Observed orders:** 7,431
- **Reported columns:** 17

## Key Performance Indicators
| Metric | Dashboard Result |
|---|---:|
| Total recorded sales | $4,598,960.87 |
| Total orders | 7,431 |
| Average order value | $618.89 |
| Unique observed customers | 4,431 |

## Key Findings
- Running Shoes generated $1,616,946.28, representing 35.2% of recorded sales.
- California was the leading billing state, with $535,786.61 in recorded sales.
- Shopify Payments accounted for 58.5% of recorded sales by gateway.
- 2,039 customers placed two or more observed orders during the reporting week.
- March 24 was the peak observed day, with $752,227.32 across 1,204 orders.

## Dashboard Features
- Sales KPI cards
- Daily sales trend analysis
- Revenue by product type
- Revenue by billing state and city
- Revenue by payment gateway
- Customer purchase-frequency analysis
- Dataset quality audit

## Business Recommendations
1. Monitor Running Shoes inventory and profitability.
2. Investigate the factors contributing to California's sales performance.
3. Monitor checkout performance across payment gateways and validate settlement records separately.
4. Study repeat purchasing patterns over a longer period.
5. Extend the analysis to monthly trends and customer retention when sufficient historical data is available.

## Limitations
- The analysis covers only seven days.
- Observed repeat orders do not establish long-term customer loyalty.
- Recorded sales include tax and should not be treated as profit.
- Dashboard figures should be validated against the source dataset before final publication.
